# Team 1 – Data Preparation and Analysis


## Script 1: `team1.R`

`team1.R` processes the raw dataset to create a cleaned and analysis-ready file. It has been done with the code given.

### Main Steps

1. **Load data** and create a unique player ID.
2. **Extract birth date parts** and compute `age`, `age²`.
3. **Convert variables** to numeric where needed.
4. **Average skin tone ratings**: `rateravg = (rater1 + rater2) / 2`.
5. **Expand dataset by number of games** (`uncount(games)`), creating one row per game.
6. **Recode card variables**:
   - Binary indicators for yellow, red, and combined cards.
   - `anyred`: any red card (direct or second yellow).
   - `anycard`: any type of card.
7. **Encode categorical variables** (club, position, league country).
8. **Add quadratic terms** (`height²`, `weight²`).
9. **Compute average IAT and Exp scores per referee country**.

### Output

The resulting `df_clean.csv` is ready for statistical analysis and saved as `teams/team01/outputs/df_clean.csv`.

## Script 2: `team1bis.R`

`team1bis.R` performs the statistical analyses given in the pdf of the team. I interpreted all of their work into this file.

### Main Steps

1. **Load required packages**, primarily `fixest` for fixed-effects regressions.
2. **Load the cleaned dataset** generated by `team1.R`.
3. **Question 1: Effect of skin tone on card probability**  
   - Linear Probability Models (LPM) for redCards, anyred, yellowCards.
   - Logistic regressions for the same outcomes.
   - Non-linear version using categorical `skintone_factor` (levels 1–5).
4. **Question 2: Effect of implicit and explicit bias (IAT / Exp)**  
   - Separate models for light-skinned (rateravg < 3/5) and dark-skinned (rateravg ≥ 3/5) players.
   - Player fixed effects regressions using average IAT or Exp score of referee’s country.
5. **Display of results**:  
   - Tables for:
     - Q1 – LPM
     - Q1 – Logit
     - Q1 – Non-linear (categorical skin tone)
     - Q2 – Implicit/explicit bias by player group

### Output

All result tables are printed to the R console. They can be redirected or exported for further reporting.
